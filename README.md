# Organizador de Imposto de Renda

Planilha moderna e estruturada para organização de dados, informes financeiros e controle de receitas para a Declaração de Imposto de Renda. 

## 📊 Funcionalidades
- **Dados Pessoais:** Estrutura objetiva para registro de informações cadastrais do declarante.
- **Saldos Bancários:** Controle de contas com validação em uma base de 50 instituições financeiras.
- **Receitas e Entradas:** Tabela zebrada para estruturação temporal de recebimentos e holerites.
- **Design Minimalista:** Interface focada em usabilidade e dados, sem linhas de grade e com paleta de cores sóbria.

## 📂 Estrutura do Arquivo
1. `01 - DADOS PESSOAIS`
2. `02 - SALDOS BANCÁRIOS`
3. `03 - RECEITAS E ENTRADAS`
4. `04 - APOIO` (Aba oculta contendo a base de dados de validação)

## 🛠️ Tecnologias Utilizadas
- Microsoft Excel (.xlsx)
- Validação de Dados 

## 🚀 Como Utilizar
1. Realize o download do arquivo `Organizador de Imposto de Renda.xlsx`.
2. Preencha a aba de **Dados Pessoais** com as informações atualizadas.
3. Na aba de **Saldos Bancários**, utilize os menus suspensos para selecionar a instituição e registre os valores.
4. Documente as entradas financeiras sequencialmente na aba de **Receitas e Entradas**.
